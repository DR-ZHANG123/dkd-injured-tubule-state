# 14a_concordance_permutation — calibrated nulls for KPMP iPT transcriptome concordance

1. **Permutation null**: DKD/HKD labels permuted 1,000 times among KPMP participants within each modality (group sizes kept; eGFR-adjusted contrast: permuted within eGFR_lower bands <30/30–39/40–49/50–59/≥60); per permutation the same-sign fraction and Spearman rho versus discovery dE (FDR<0.10 genes) are recomputed; empirical P = (#perm ≥ observed + 1)/(n + 1).
2. **Fast statistic (primary, `nb_glm_fixed_dispersion`)**: the DESeq2 NB GLM (~ sex [+ z-scored eGFR_lower] + group, offset log size factor) refitted by vectorised IRLS with size factors and dispersions fixed at pydeseq2's estimates on the observed labels; on observed labels its log2FC sign equals DESeq2 for 100% of set genes and 99.8–99.9% of all genes (`fast_statistic_validation.tsv`), and 20 permutations/modality refitted with full DESeq2 agree in sign for 99.7–99.9% of genes (`deseq2_permutation_check.tsv`).
3. The simpler log2 ratio of size-factor-normalised group means (+1 pseudocount; rows `primary = False`) agrees with DESeq2 in sign for only 87.8% (sn) / 94.3% (sc) of the discovery genes, failing the pre-set 95% criterion, so it is reported as a sensitivity row only.
4. **Background null**: 1,000 random gene sets of the same size drawn from all genes tested in both discovery and KPMP, matched on discovery baseMean decile, scored with the observed KPMP DESeq2 log2FC (`observed_frac`, `observed_rho` are the DESeq2 values; perm P uses the fast-statistic observed value `*_fast`).
5. Negative control `shared_injury_genes`: SharedInjury_up/down genes (05_lock_programme) with reference direction (dD + dN)/2 from the discovery SN-stratum PT lineage DE; background pool for it = all genes tested in that lineage DE.
